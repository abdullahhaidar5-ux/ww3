# HANDOFF - announcer (orch/announcer)
Shipped: `src/09d-announcer.js` - a calm radio announcer with the 17 requested lines (Building / Construction complete / Unit ready / Upgrade complete / Insufficient funds / Low power / Power restored / base + units under attack / Unit lost / Building lost / Cannot build here / Strike ready / Enemy strike detected / Supply line cut / Road captured / Reinforcements have arrived). Original lines, text in en, fa, ar, ru, zh, he (ANN_TXT); every other nation speaks English.
Hooks: `pushLog` (08-ui.js) calls `annFromLog`; message regexes in ANN_RE; silent log kinds `ann:<key>` for events with no visible text (building start, complete, upgrade, funds, cannot build) added in 03-sim.js. Throttle `annGate`: same line 6 s, under-attack 20 s, never overlapping, Test range x3 slower and no base-attack line. Settings > Audio "Announcer volume" slider (SET.ann, default 80). Guard: orch/decisions.mjs ("announcer").

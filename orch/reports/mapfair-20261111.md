## Result
- **1,532 computer-vs-computer battles on all 116 maps, 317 map × player-count layouts, no errors.** Full table: `mapfair-20261111.txt`.
- **313 of 317 layouts: no start position wins more than chance allows.**
- Four layouts were flagged (p < 0.01): bosphorus 4 players, eilatgulf 6, najd 8, volga 4. With 317 layouts about three
  false alarms are expected by chance, so each got **two more rounds with other seeds and nations (128 battles, `mapfair-20261111-flagged-r2r3.txt`):
  none of the four repeats** (bosphorus 4p seat 2: 100 % → 22 %; volga 4p seat 2: 100 % → 16 %; eilatgulf 6p seat 4: 83 % → 22 %;
  najd 8p seat 4: 64 % → 27 %). They were chance.

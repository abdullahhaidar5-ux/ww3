# trees (2026-11-04)
Shipped: living trees now use **real photo textures** (Poly Haven, CC0: Fir Tree 01 needle twigs; Tree Small 02 / Island Tree 01 leaves) instead of the canvas-drawn sprigs. Shipped as one small model `tree_tex` (2 WebP textures, ~60 KB). Conifers rebuilt as drooping whorls of real fir twigs (17 whorls x 7 cards, Low 9x4), oak/acacia as clouds of real leafy twigs (oak 64 cards, acacia clustered 16/branch), palms now have real feathery fronds (were pale cones). Per-biome tint (green = deep greens, desert = dusty olive-gold), per-card shade by height, existing wind sway/shadow proxy/instancing kept. Falls back to the old procedural look if `tree_tex` fails to load. Tree positions/sim untouched.
Not done: full Poly Haven 3D tree meshes (fir 7M tris, island trees 1-2M tris; 20-40k tris after decimation x ~900 trees is too heavy and alpha-card decimation breaks leaves), bark texture on trunks, distance impostors (terrain2 branch did not exist when this ran), dead trees, cypress/olive/shrub species, Zagros and snow-map shots, FPS numbers (swiftshader only).
Shots: orch/shots/trees/ (a1-a3: fulda, desert rubalkhali, close-up, phone). Script: orch/treeshots.mjs.

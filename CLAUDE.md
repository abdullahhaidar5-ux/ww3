## Every change

Edit `src/` → `python3 orch/build.py` (syntax-checks; refuses to write on error) → `node orch/smoke.mjs` prints `SMOKE PASS` →
`node orch/smooth.mjs` prints `SMOOTH PASS` (re-baseline per `orch/SMOOTH.md` only if intentionally heavier) →
`node orch/grandtest.mjs` PASS → commit `src/` **and** `index.html` **and** `grand.<hash>.js` (plus `sw.js`, `models/` if changed) together. Never write `</script` in `src/` (use `<\/script`). Don't touch the vendored libraries
or the `MODEL_FILES`/`GRAND_FILE` lines (`build.py` writes them). `python3 orch/build.py --check` must pass.
Smoke runs the page with `?lazy=1` (battles must work without the grand bundle); other tests run automated browsers, which load the grand bundle with the page.
Never force-push `main`; rebase on `origin/main` before every push; `index.html`/`grand.*.js` conflicts → rebuild; HISTORY conflicts keep both sides.
Describe each change in plain words a player would understand.

## Standing decisions (short; dates and quotes in orch/DECISIONS.md)

- **It's a world simulator:** the grand campaign simulates the real world. For every feature write down and build its chain: who reacts (AI nations by real interests/alliances, populations, markets, UN/blocs, media); second-order effects across systems; realistic Nov-2026 starting data (look it up); counter-play; costs. One shared world state (GMOD rows + one event engine). **If in doubt, make it realistic** (real timings/ranges/numbers). Calibrate on real history base rates (wars rare and long, capitals rarely fall fast, regimes fall from within); real 2026 start in `orch/REAL-2026.md`; EU4 wiki is the reference for grand screens/mechanics. Tactical battles stay balanced games.
- **Vision:** massive columns of infantry and vehicles in intense combat, aircraft/drones overhead; Company of Heroes / Broken Arrow realism in real gameplay; flanking, cover, suppression. **No decorative or ambient aircraft or drones** — only real, controllable ones fly.
- **Controls:** left-click selects (drag = box, Shift adds, double-click = that type on screen); right-click moves/attacks (right-drag = infantry line); F+click attack-move; G+click guard, Ctrl+click force-fire, Alt+click waypoints; **W A S D only scroll the camera**; Stop = X; **Q rotates the battle camera** (hold Q + mouse, tap = 45° clockwise, Shift+Q counter-clockwise, Home/double-tap = north-up; view only); **Ctrl+A selects the whole army**; left-click ground with a production building selected sets its rally point; units deselect after an order (Settings toggle; Shift keeps them). Getting in/out needs no button: enter = select units + right-click own building/vehicle/transport/tunnel; leave a building = select it + right-click ground; leave a vehicle = select it + right-click itself (unload here) or Alt+right-click a spot. Mouse stays inside the window on PC (pointer lock, Esc releases, Settings toggle). Command bar text big and readable.
- **UI flow:** one job per screen/window, smooth transitions, Back/Esc one step back, elegant text menu items, small buttons — never cram everything on one screen, no big ugly buttons (menus, setup, grand panels, battle HUD).
- **Factions:** 54 full nations (22 live at first, rest via `NEWNAT`/`11z-nations-*`) + fictional OB "Palestine Islamic Brigade" and BI "Desert Islamic Faction" (inspired-by only: never a real group's name/flag/emblem/slogan/leader; no terror/hostage/suicide/civilian-target mechanics; military vs military). Names: RS = "Lebanese Shia", DW = "Zaidi Shia Movement" (= Yemen), RV = "Iraqi Shia Brigades" (south Iraq, never the real organisation's name/emblem/leaders). Shia factions = IR, RS, DW, RV. EU retires as a nation (FR/DE/PL carry its units, voices, Fulda map; on the grand map the EU is an alliance with a joint-operations bonus); every other grand-map country is a playable minor nation (shared regional army, own flag/name/colours). IM was removed on purpose. Keep the upgrade name **"Radwan Training"** exactly. RS must read as a Lebanese mountain Shia resistance force (Lebanon home, Lebanese-dialect voices, Ashura/"Ya Hussein" motifs, tunnels, ATGM teams, rockets, drones, mountain forts) with an original emblem.
- **Morale styles** (one per nation, equal power, tuned by numbers not by moving nations; full table `orch/SYSTEMS.md`): Zealous (**NEVER rout, in any form of the game** — no rout, retreat, flee, crew-bail-out or AI pull-back in Conquest, Battle, Missions or Fight-it, incl. shaken starts; cost = heavier losses; guard `fearlessT`/`msOf(..).rout===0` in orch/decisions.mjs; IR, RS, DW, RV, KP, OB, BI), Professional (rout below 15% of enemy strength; e.g. RU, CN, PK, EG), Home defenders (rout below 8% home / 20% abroad; e.g. IN, UA, CU, VN, BR, NG, ID, JO, OM, ZA, TH), Firepower-reliant (rout below 25%, stronger fire support; UAE, SA, IL). "Strength in numbers" style is removed. Grand-map morale moves with victories/defeats, casualties, war length, losing home/holy places, national/religious days; collapse = shaken troops, forced peace talks, coups/civil war.
- **Signature assets** (Ayatollah IR/RS/DW, Dear Leader KP, Bunker Buster US/IL/RU/CN, Mountain Fortress IR/RS/AF/KD/DW/KP) are **playable in Conquest, Battle, Missions and sandbox for those nations only** (Abdullah 2026-11-07 22:38), but in grand-campaign Fight-it battles the Ayatollah/Dear Leader and Bunker Buster stay OUT (nothing built or bought there; the grand map's pre-built defender Mountain Fortress stays). On the grand map they are leader figures / province building / strike. Leader abilities: one shared system `src/03i-leaders.js` (`T.ld`, action `{t:'ldr'}`, E / Shift+E; Ayatollah: Steadfast, Path of Hussein, Sermon, Call to Arms; Dear Leader: On-the-spot guidance, Unbreakable Spirit, Supreme Commander's Order, Mass Mobilization; guard `orch/leaders.mjs`). Signature assets are unique per nation, not copied are unique per nation (`orch/SIGNATURES.md`): one Ayatollah leads IR/RS/DW (permanent alliance while he leads), with sub-leaders RS Secretary-General, DW Leader of the Revolution, RV Chairman + Grand Ayatollah of Najaf (fictional names, never real leaders); Dear Leader KP only; Mountain Fortress IR, RS, AF, KD, DW, KP; Bunker Buster US, IL, RU, CN.

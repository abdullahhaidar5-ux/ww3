## Every change

Edit `src/` → `python3 orch/build.py` (syntax-checks; refuses to write on error) → `node orch/smoke.mjs` prints `SMOKE PASS` →
`node orch/smooth.mjs` prints `SMOOTH PASS` (re-baseline per `orch/SMOOTH.md` only if intentionally heavier) →
`node orch/grandtest.mjs` PASS → commit `src/` **and** `index.html` **and** `grand.<hash>.js` (plus `sw.js`, `models/` if changed) together. Never write `</script` in `src/` (use `<\/script`). Don't touch the vendored libraries
or the `MODEL_FILES`/`GRAND_FILE` lines (`build.py` writes them). `python3 orch/build.py --check` must pass.
Smoke runs the page with `?lazy=1` (battles must work without the grand bundle); other tests run automated browsers, which load the grand bundle with the page.
Never force-push `main`; rebase on `origin/main` before every push; `index.html`/`grand.*.js` conflicts → rebuild; HISTORY conflicts keep both sides.
Describe each change in plain words a player would understand.

## Ground rules

- **Test on GitHub, not here:** the cloud sandboxes are too slow to run `orch/smooth.mjs` / `orch/grandsmooth.mjs` (they time out or fail on unchanged main) — do NOT conclude anything from a local smooth run and do not stop because of one: run the gate on GitHub's runners with `orch/cigate.sh` (pushes your commit to `gate/<sha>`, waits for the `gate/*` statuses). Main was fully green (28 of 28) on 2026-11-11 with conductor train 5; a change ships only if its own `orch/cigate.sh` run is green.
- **Main is for landings only (2026-11-10 19:25, ORCH):** every push to `main` restarts the live-site update (GitHub Pages cancels the build in progress) and a full test run; with many helpers pushing queue marks every few minutes the live site did not update for 6 hours. So: do NOT push queue marks, logs, handoffs, reports or other docs-only commits to `main` on their own. To take a queue item, create its lock branch instead: `git push origin HEAD:refs/heads/taken/<short-item-name>` — if that branch already exists (`git ls-remote --heads origin 'taken/*'`) and is younger than 12 h the item is taken, pick the next; a `[>]` mark already on main also still counts. Change `orch/QUEUE.md`, HISTORY, LOOP, BRIEF and reports only inside the commit that lands code (or on your own branch). This overrides any helper prompt that says to push a mark to main first.
- **Smooth first:** every visual change keeps `gate/smooth-pc`, `gate/smooth-mp`, `gate/grandsmooth` green; new props/decals/labels are instanced or merged per material, never one mesh each; never raise a budget or re-baseline to pass. Smooth gate red on main → all look work stops until fixed (the lane that broke it fixes it).
- **A decision is done only when its leftovers are gone:** when you ship or change a decision, grep and play-test for every trace of the old way (buttons, hotkeys, menu items, tooltips, encyclopedia/what's-new text, AI build lists, tests, saves), remove it in the same ship, and add a guard (`orch/smoke.mjs` or `orch/decisions.mjs`).
- **One system per idea:** read `orch/SYSTEMS.md`, extend the owner of your idea, never add a second system for the same job. New sim state goes into the checkpoint (`src/07b-ckpt.js`) so saves and host migration work; new hotkeys go in the one key table.
- **Kaizen & lanes:** read `orch/BRIEF.md`; follow `orch/KAIZEN.md` (measure → one small high-value change → prove → ship → log) and the lanes in `orch/PLAN-SAT.md` (one owner per file). Loops obey `orch/BUDGET.md` (max 8 helpers at once, 24 iterations/loop/day — full throttle since 2026-11-10; landings on main still go one at a time, each on its own gate run, stop cleanly on rate limits). Grand stage branches `orch/grand1…7`, `grand4b`, `integrate2` follow `orch/CHAIN.md` (first check before work, last step starts the next stage).
- Work only in your squad's files unless ORCH assigned otherwise; small verifiable changes; no new runtime dependencies from other hosts (Three.js r186 via `orch/three/vendor.mjs`, PeerJS bundled); never delete branches/files you didn't create or rewrite history.
- **Save early:** push your work branch after every commit (`git push origin HEAD:refs/heads/orch/<name>`), before any long test or wait; work that exists only in your sandbox is lost if the session stops.
- **Ship what is green in small pieces; never leave main broken.** Write `orch/HANDOFF-<branch>.md` when stopping early.

## Standing decisions (short; dates and quotes in orch/DECISIONS.md)

- **It's a world simulator:** the grand campaign simulates the real world. For every feature write down and build its chain: who reacts (AI nations by real interests/alliances, populations, markets, UN/blocs, media); second-order effects across systems; realistic Nov-2026 starting data (look it up); counter-play; costs. One shared world state (GMOD rows + one event engine). **If in doubt, make it realistic** (real timings/ranges/numbers). Calibrate on real history base rates (wars rare and long, capitals rarely fall fast, regimes fall from within); real 2026 start in `orch/REAL-2026.md`; EU4 wiki is the reference for grand screens/mechanics. Tactical battles stay balanced games.
- **Vision:** massive columns of infantry and vehicles in intense combat, aircraft/drones overhead; Company of Heroes / Broken Arrow realism in real gameplay; flanking, cover, suppression. **No decorative or ambient aircraft or drones** — only real, controllable ones fly.
- **Controls:** left-click selects (drag = box, Shift adds, double-click = that type on screen); right-click moves/attacks (right-drag = infantry line); F+click attack-move; G+click guard, Ctrl+click force-fire, Alt+click waypoints; **W A S D only scroll the camera**; Stop = X; **Q rotates the battle camera** (hold Q + mouse, tap = 45° clockwise, Shift+Q counter-clockwise, Home/double-tap = north-up; view only); **Ctrl+A selects the whole army**; left-click ground with a production building selected sets its rally point; units deselect after an order (Settings toggle; Shift keeps them). Getting in/out needs no button: enter = select units + right-click own building/vehicle/transport/tunnel; leave a building = select it + right-click ground; leave a vehicle = select it + right-click itself (unload here) or Alt+right-click a spot. Mouse stays inside the window on PC (pointer lock, Esc releases, Settings toggle). Command bar text big and readable.
- **UI flow:** one job per screen/window, smooth transitions, Back/Esc one step back, elegant text menu items, small buttons — never cram everything on one screen, no big ugly buttons (menus, setup, grand panels, battle HUD).
- **Factions:** 54 full nations (22 live at first, rest via `NEWNAT`/`11z-nations-*`) + fictional OB "Palestine Islamic Brigade" and BI "Desert Islamic Faction" (inspired-by only: never a real group's name/flag/emblem/slogan/leader; no terror/hostage/suicide/civilian-target mechanics; military vs military).
